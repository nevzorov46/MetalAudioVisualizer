# Metal Audio Visualizer

A real-time audio visualizer built with Metal, AVAudioEngine, and SwiftUI.

The project plays four isolated audio stems simultaneously:

- 🎤 Vocals
- 🥁 Drums
- 🎸 Bass
- 🎹 Other

Each stem is analyzed independently using AVAudioEngine taps and visualized in real time using a custom Metal rendering pipeline.

## Technologies

- Swift
- SwiftUI
- Metal
- AVAudioEngine
- MTKView
- Custom shaders

## Features

- 60 FPS rendering
- GPU-driven visualization
- Real-time RMS analysis
- Independent visualization for four audio stems
